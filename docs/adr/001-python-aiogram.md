# ADR 001: Вибір Python та асинхронного фреймворку `aiogram` для розробки бота

- **Статус:** Прийнято
- **Дата:** 2026-03-30 (або дата створення)

## Контекст

Для побудови інтерфейсу користувача та керування станами діалогу в Telegram необхідно обрати мову програмування та відповідний фреймворк. Система вимагає високої асинхронності для обробки паралельних запитів користувачів, зручної інтеграції з асинхронними API сторонніх LLM-сервісів та розвиненої екосистеми для інструментів парсингу й генерації документів.

## Рішення

Обрано мову **Python** у поєднанні з асинхронним фреймворком **`aiogram`**.

## Наслідки

- **Позитивні:**
  - Нативна підтримка асинхронності (`Asyncio`) забезпечує ефективну обробку багатьох з'єднань одночасно.
  - `aiogram` гарантує швидку реакцію на оновлення Telegram API та зручне управління станами (FSM) при покроковому введенні даних і завантаженні резюме.
  - Єдина мова стеку (Python) спрощує інтеграцію з модулями машинного навчання та LLM.
- **Негативні:**
  - Споживання оперативної пам'яті вище, ніж у комільованих мов (наприклад, Go або Rust), що компенсується горизонтальним масштабуванням контейнерів у хмарному середовищі.
