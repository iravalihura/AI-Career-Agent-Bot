# ADR 002: Вибір реляційної бази даних PostgreSQL

- **Статус:** Прийнято
- **Дата:** 2026-03-30 (або дата створення)

## Контекст

Платформа повинна зберігати структуровані дані про профілі користувачів, завантажені резюме, зібрані з різних джерел вакансії, а також історію відгуків та статуси подачі заяв. Дані мають чіткі взаємозв'язки (наприклад, відгук належить конкретному користувачеві та відповідає певній вакансії).

## Рішення

Обрано реляційну систему керування базами даних **PostgreSQL**.

## Наслідки

- **Позитивні:**
  - Гарантія транзакційної цілісності (ACID) та надійні реляційні зв'язки між сутностями.
  - Підтримка повнотекстового пошуку та зручне зберігання напівструктурованих даних завдяки типу `JSONB` (що критично важливо для збереження різнорідних параметрів зібраних вакансій).
  - Зв'язка з Python надійно реалізується через перевірені інструменти міграцій (`Alembic`) та ORM (`SQLAlchemy`).
- **Негативні:**
  - Жорстка схема вимагає ретельного планування міграцій при зміні бізнес-логіки обробки резюме чи вакансій.
