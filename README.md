# 🤖 AI Career Agent Bot

Інтелектуальний Telegram-бот для автоматизації пошуку роботи, AI-оцінки сумісності вакансій та генерації професійних резюме.

---

## 📌 1. Концепція проєкту

**AI Career Agent Bot** — це екосистема для кандидатів, яка мінімізує рутину під час працевлаштування. Бот збирає нові вакансії з різних джерел, аналізує їх за допомогою великих мовних моделей (LLM), розраховує відсоток сумісності з профілем користувача та допомагає адаптувати резюме і супровідні листи.

## 🛠 3. Технологічний стек

- **Мова програмування:** Python 3.11+
- **Telegram Фреймворк:** `aiogram` (асинхронний інтерфейс, FSM)
- **База даних:** PostgreSQL (зберігання профілів, резюме, вакансій та відгуків)
- **Контейнеризація:** Docker & Docker Compose
- **Штучний інтелект:** OpenAI API / Anthropic Claude API
- **Парсинг та генерація:** BeautifulSoup, Playwright, ReportLab

---

## 🔄 4. Життєвий цикл та DevOps

- **Методологія:** Scrum (двотижневі спринти, інкретний випуск функціоналу).
- **Інтеграція DevOps:** Налаштовано концепцію безперервної доставки (**Continuous Delivery**). Кожне оновлення автоматично перевіряється в CI/CD пайплайні, пакується в Docker-контейнери та розгортається на продакшн-сервері без простою.
